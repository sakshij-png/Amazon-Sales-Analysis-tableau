# 🛍️ Amazon Sales Analysis Dashboard

An interactive sales analytics dashboard built using **Tableau Public** to explore Amazon sales performance, product categories, order status, courier performance, and regional distribution across India.

## 🎯 Project Overview

The objective of this project is to analyze Amazon sales data and transform it into meaningful visual insights using interactive dashboards. The project helps explore sales trends, product demand, order fulfillment, and regional sales distribution.

## 🛠️ Tools & Technologies

- **Tableau Public** — Data visualization and dashboard development
- **Microsoft Excel** — Dataset storage and data preparation, where applicable

## 📈 Dashboard Features

- **KPI Overview:** Total quantity, total amount, product count, category count, and size count.
- **Weekly Sales Trends:** Analyze weekly variations in order quantity and sales amount.
- **Category Analysis:** Compare product quantities across different categories.
- **Order Status Analysis:** Explore order quantities across different order statuses.
- **Courier Status Analysis:** Compare shipped, unshipped, and cancelled orders.
- **Regional Analysis:** Visualize sales quantities across Indian states.
- **Product Size Analysis:** Examine demand across different product sizes.
- **Sales Channel Analysis:** Compare quantities across available sales channels.
- **Interactive Filtering:** Filter dashboard data by product category.

## 💡 Business Questions Explored

- How do sales amounts and order quantities vary over time?
- Which product categories contribute the most to order quantity?
- What is the distribution of orders across different statuses?
- How does courier status vary across orders?
- Which Indian states have the highest order quantities?
- Which product sizes show stronger demand?
- How are orders distributed across sales channels?

## 🔍 Key Insights

The dashboard supports exploration of:

- Weekly sales and quantity trends.
- Product category and size demand patterns.
- Order fulfillment and courier status distribution.
- Differences in order quantities across Indian states.
- Sales channel distribution.
