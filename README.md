# 📊 Amazon Sales Analysis Dashboard

An interactive sales analytics dashboard built using **Tableau Public** to explore Amazon sales performance, product categories, order quantities, courier status, and regional distribution.

## 📸 Dashboard Preview

![Amazon Sales Dashboard](amazon_sales_dashboard.png)

## 🎯 Project Objective

The objective of this project is to analyze Amazon sales data through interactive visualizations and identify patterns in product demand, sales performance, order fulfillment, and regional distribution.

## 🛠️ Tools & Technologies

- **Tableau Public** — Data visualization and dashboard development
- **Microsoft Excel / CSV** — Data source and data preparation, as applicable

## 📈 Dashboard Features

- **KPI Summary:** Total quantity, total amount, product count, category count, and size count.
- **Weekly Sales Trends:** Analyze changes in quantity and amount over time.
- **Order Status Analysis:** Explore shipped, cancelled, pending, and other order statuses.
- **Courier Status:** Compare shipped, unshipped, and cancelled quantities.
- **Product Category Analysis:** Compare quantities across product categories.
- **Regional Analysis:** Explore sales quantities across Indian states.
- **Product Size Analysis:** Compare product quantities across different sizes.
- **Sales Channel Analysis:** Examine Amazon.in and non-Amazon sales channels.
- **Interactive Filtering:** Filter the dashboard by product category.

## 🔍 Key Observations

- Shipped orders account for approximately 94.14% of the courier-status distribution shown in the dashboard.
- The dashboard shows variations in weekly order quantities and sales amounts.
- Product quantities vary across sizes and categories.
- Regional and shipping-service breakdowns help compare order quantities across states.

*Observations are based on the current dashboard and may change when filters are applied.*
